# 按风险定档

- **轻档 light** 适合单点修改、至多三条行为，接口、库表、配置和公共逻辑均保持原状。合写背景、验收、结论与验证，缺陷还要写根因。
- **标准档 standard** 用于其余常规工作。分别写需求和方案，按验收点列任务。确认契约后实现，收尾后独立核对。
- **重档 heavy** 用于接口或库表变化、迁移、跨仓库、公共逻辑变化或业务规则繁多的工作。给出影响范围的检索依据、旧数据与调用方的过渡、回退办法。确认前请独立读者评审遗漏的边界、数据风险与契约冲突。

用 `craft method tier` 看当前建议、命中路径与依据。基础分支不可读时，结果会指出缺失的基线。把工具看不到的影响范围一并告诉人，由人在确认时定档。实现中发现风险升高，先补齐方案并重新确认。
